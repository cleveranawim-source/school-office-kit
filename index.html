1

템플릿으로 내 저장소 만들기

GitHub 저장소에서 Use this template → Create a new repository를 누르고, 이름을 정한 뒤 Private(비공개)을 고릅니다.

꼭 비공개로. 이 저장소에 우리 학교 정보와 구축 기록이 쌓입니다.
2

내 컴퓨터로 받아 폴더 열기

터미널에서 아래처럼 받고, 그 폴더에서 Claude Code(claude) 또는 Codex(codex)를 실행합니다.

# 「내아이디/저장소이름」을 1단계에서 만든 것으로 바꿉니다 $ git clone https://github.com/내아이디/저장소이름.git $ cd 저장소이름 $ claude # 또는 codex

기술보다 이쪽이 더 중요합니다. 미리 알면 중간에 지치지 않습니다.

시간 — 한 학기

원본 학교는 거의 매일 붙어서 한 달 걸렸습니다. 수업하면서라면 핵심 기능(급식·공지·시간표·자료실·알림)까지 한 학기를 잡으세요.

책임 — 막히는 게 정상

교직원 정보를 다루는 사이트입니다. 관리자 합의, 학교 공용 계정, 정보보안 확인이 없으면 키트가 1단계로 넘어가지 않습니다.

비용 — 무료로 시작

Supabase·Vercel 무료 요금제로 시작합니다. AI 도우미를 붙이면 월 몇만 원 — 결제 주체를 먼저 정하고 회사 콘솔에 지출 한도를 겁니다.

첫 목표 — 작게

핵심 기능을 만들어 시범 사용자 3~5명에게 한 주 써 보게 하는 것. 업무 요청·교실 칠판·AI 도우미 같은 큰 기능은 그 뒤에.

새 함정, 더 꼼꼼한 관문 검사가 생기면 새 판이 나옵니다. 템플릿으로 만든 저장소는 저절로 따라오지 않으니, 가끔 이렇게 말하세요.

「키트 업데이트해 줘」

AI가 바뀌는 것을 먼저 보여 주고, 허락을 받은 뒤에 적용합니다. 직접 하려면:

node kit/scripts/update-kit.mjs

우리 학교 것은 안전합니다

앱 코드, 우리 학교 정보, 구축 기록은 건드리지 않습니다. 키트 문서라도 우리가 고친 파일은 덮어쓰지 않고, 키트 쪽도 바뀌었으면 새 판을 옆에 두어 함께 합칩니다.
