## 1. 아이폰·홈 화면 앱

1. ★★★ **하단 탭이 본문 중간에 떠 보이거나 스크롤에 딸려 올라온다 / 글을 쓰는 동안 키보드를 따라 올라온 탭이 입력줄을 가린다** → 아이폰은 주소창을 접었다 펼 때 `position: fixed` 요소를 늦게 그린다. 화면 끝을 당기는 되튐도 같은 현상. 키보드가 올라오면 화면 아래 붙은 탭도 함께 올라온다 → **하단 탭은 `fixed`가 아니라 본문 흐름 끝의 `sticky bottom-0`. `html, body { overscroll-behavior-y: none }`. 글 칸에 포커스가 있는 동안은 탭을 숨기고 탭 높이 변수(9번)를 0으로 — 입력줄이 키보드 바로 위에 붙는다.** (2026-10 고침)
2. ★★★ **입력칸을 누르면 화면이 확대되고, 가로로 밀면 페이지 전체가 움직인다** → 아이폰은 글자 16px 미만 입력칸에서 확대한다. 밀어 낸 카드가 화면 밖으로 나가면 문서 폭이 늘어난다 → **입력칸 `font-size: max(16px, 1em)`, `touch-action: manipulation`. 스와이프 영역은 `overflow-x: clip` + `touch-action: pan-y pinch-zoom`.**
3. ★★★ **홈 화면 앱에서 파일을 받으면 파일 화면으로 넘어가 돌아올 단추가 없다** → 독립 창에서 `<a download>`로 이동했기 때문 → **fetch로 받아 휴대폰은 `navigator.share({ files })` 공유 창, PC는 blob 내려받기.**
4. ★★★ **홈 화면 앱에서 바깥 링크를 누르면 다른 브라우저로 튀어 나간다** → `target=_blank` → **앱 안 보기 화면(iframe)으로 열고, 끼워 넣기를 막는 사이트만 같은 창으로(64번). 보기 화면 주소에는 바깥 주소·제목을 싣지 않는다 — 「자료 id + 몇 번째 링크」만 싣고, 서버가 보는 사람의 권한으로 그 자료를 읽어 주소를 꺼낸다. 주소를 그대로 받으면 남이 만든 링크로 진짜 앱 머리줄 아래 가짜 로그인 화면을 띄울 수 있다.** (2026-10 고침)
5. ★★★ **알림을 눌러도 아이폰에서는 그 화면으로 안 간다** → iOS 서비스 워커에는 `WindowClient.navigate()`가 없다 → **창을 `focus()`한 뒤 `postMessage({ type: "open", url })`로 건네고, 페이지가 이동한다. 같은 출처 경로(`/`로 시작, `//` 아님)만 따른다.**
6. ★★★ **아이폰에서 알림 켜기가 안 되거나 「불러오는 중」에서 멈춘다** → iOS는 **홈 화면에 추가한 앱에서만** 웹푸시를 받는다. 서비스 워커 등록이 실패하면 `serviceWorker.ready`가 영원히 기다린다 → **홈 화면 앱인지 검사해 「홈 화면에 추가」 안내를 따로 보여 주고, `ready`에 5초 제한.**
7. ★★★ **`sw.js`를 고쳤는데 하루씩 옛 동작을 한다** → 브라우저가 `sw.js`를 캐시하고 새 워커는 대기한다 → **`/sw.js`에 `Cache-Control: no-cache`, install에서 `skipWaiting()`, activate에서 `clients.claim()`. 화면을 캐시하지 않는 워커일 때만 안전.**
8. ★★ **휴대폰이 잠들면 쓰던 AI 답이 사라진다** → 스트림이 끊김 → **서버는 화면이 끊겨도 그때까지 만든 답을 저장한다.**
9. ★★ **사파리 비공개 모드에서 화면이 깨진다 / 메뉴 이모지가 기기마다 다르다 / 탭 높이가 어긋난다** → localStorage는 접근만 해도 예외를 던진다. 이모지 글꼴은 OS마다 다르다. 홈 막대 여백은 기기마다 다르다 → **저장소 접근은 모두 try/catch. 메뉴는 선 아이콘. 탭 높이는 실측해서 CSS 변수로.**
10. ★★ **안드로이드에서 「홈 화면에 추가」한 특수 화면(교실 칠판)이 교사용 첫 화면으로 열린다** → 공용 매니페스트의 `start_url`이 `/` → **용도가 다른 화면에는 전용 매니페스트(start_url·scope·이름).**

_2.0 추가_

86. ★★ **페이지가 바뀔 때 화면 아래 고정 단추가 위쪽에 그려졌다가 툭 내려온다** → 페이지 전환 움직임에 `transform`을 쓰면 그동안 감싼 층이 `position: fixed`의 기준이 된다 → **전환 움직임은 `opacity`만. 고정 요소를 품은 층에는 `transform`·`filter`를 걸지 않는다.**
87. ★★ **올라오는 창(`<dialog>`) 안 서명 판에 그어도 아무것도 안 남고 「저장」이 조용히 멈춘다** → 창이 열리기 전(크기 0)에 캔버스 크기를 재서 0×0 판이 됐다 → **캔버스 크기는 `ResizeObserver`로, 크기가 정해지거나 바뀔 때 맞춘다. `<dialog>`는 iOS 15.4 미만에서 뜨지 않는다는 것을 알고 쓴다.**
88. ★★ **아이폰에서 날짜·고르기 칸만 높이·둥근 정도·글자 자리가 다른 칸과 어긋난다** → 사파리가 `select`·`date` 칸에 자기 모양을 입힌다 → **`appearance: none`으로 기본 모양을 끄고 화살표는 직접 그린다. 날짜 값은 `::-webkit-date-and-time-value { text-align: left }`.**
89. ★ **안드로이드에서 색이 멋대로 뒤집힌다 / PC에서 단추에 손가락 커서가 안 나온다** → 크롬·삼성 인터넷의 「강제 다크 모드」. Tailwind 4는 `button`의 기본 커서를 화살표로 둔다 → **다크 화면을 따로 만들지 않는다면 viewport에 `colorScheme: "only light"`. 누를 수 있는 단추·고르기 상자는 `cursor: pointer`를 기본으로.**
90. ★ **아이폰에서 진동(햅틱)이 안 난다 / 스크롤하다 탭이 눌린다** → 아이폰 사파리에는 `navigator.vibrate`가 없고, 손가락이 스위치(`<input type="checkbox" switch>`)를 직접 눌러야 햅틱이 난다. 투명 스위치는 밀어도 켜진다 → **진동은 안드로이드만 기본으로. 아이폰에 꼭 필요하면 링크 옆(안이 아니라)에 투명 스위치를 겹치고, 손가락이 10px 넘게 움직였으면 누름으로 치지 않는다.**

## 2. 한글·날짜·시간대

11. ★★★ **이름을 정확히 쳤는데 「찾을 수 없음」** → 자판에 따라 한글이 자모로 쪼개져(NFD) 들어오고 공백이 섞인다 → **비교 전에 `normalize("NFC")` + 공백 제거. 초성 검색 지원. 한 사람으로 좁혀질 때만 자동 선택.**
12. ★★★ **자정~오전 9시에 「오늘 일정」이 하루 어긋난다 / 종일 일정이 하루 밀린다** → 서버(UTC)에서 오늘을 계산했다. 캘린더(ICS)의 종일 일정을 서버 시간대 날짜로 만들었다 → **「오늘」은 항상 `Asia/Seoul`로. 하루 범위는 `YYYY-MM-DDT00:00:00+09:00`. 종일 일정은 연·월·일만 꺼내 서울 자정으로 다시 만든다.**
13. ★★★ **마감 시각이 9시간 어긋나 「이미 지난 시각」으로 거부된다** → `<input type="datetime-local">` 값에는 시간대가 없는데 UTC 서버가 그대로 읽었다 → **서버에서 `${값}:00+09:00`으로 읽는다. 서버 시간대와 무관하게 통과하는 테스트.**
14. ★★★ **크론이 엉뚱한 시각·요일에 돈다** → pg_cron·Vercel 크론은 UTC. 서울 08시는 UTC 전날 23시라 **요일까지 하루 밀린다** → **평일 08:00~17:59 서울 = `* 23 * * 0-4` + `* 0-8 * * 1-5` 두 줄. 평일 07:50 = `50 22 * * 0-4`. 매일 03:00 = `0 18 * * *`. 식 옆에 서울 시각을 주석으로.**
15. ★★ **「1월 5일」이 작년 날짜로 저장된다 / 학년도 정리가 어긋난다 / 글 속 「지난 7월 15일」이 내년 마감으로 잡힌다** → 연도 없는 날짜를 그대로 읽었다. 학년도는 3월에 시작한다. 날짜를 찾을 때 쓰임새를 가리지 않았다 → **앞으로 올 날을 받는 칸(결석 날짜 등)은 한 달 넘게 지난 날이면 내년으로. 글에서 마감을 찾아 미리 채울 때는 지난 날짜를 버리고, 내년으로 넘기는 것은 11~12월에 1~2월을 쓸 때만. 「1/2학년」 「3/4분기」 같은 빗금 숫자는 날짜가 아니다. 미리 채운 마감은 보내기 전에 보이는 이름표로 두고, 보이지 않는 곳에서 정하지 않는다. 학년도 경계는 3월 1일.** (2026-10 고침)
16. ★★★ **재량휴업일에 알림이 오고 「오늘 수업」이 뜬다 / 방학식 날을 쉬는 날로 본다 / 기념일(국군의날 등)에 알림이 쉰다 / 대체공휴일에도 「다음 수업 월요일」** → 쉬는 날 판정이 화면·알림·배달마다 따로였다. 공휴일 캘린더에는 기념일이 섞이고, 학교 달력에만 있는 쉬는 날(재량휴업·개교기념일·방학)에는 공휴일 표시가 없다 → **판정 함수 하나 = 「공휴일」로 표시된 것 + 학교 달력의 종일 일정 중 제목이 「휴일·휴업·개교기념일·방학」인 것(「방학식」은 수업하는 날). 홈·현황판·알림·배달·주간소식·다음 수업일 계산이 모두 이 함수를 쓰고, 학교 달력 제목을 표로 시험한다.** (2026-10 고침)
17. ★★ **시트의 날짜 칸을 엉뚱하게 찾는다** → 학교 시트의 「10월」 탭이 작년 달력 복사본이라 요일이 맞지 않았다 → **요일을 계산하지 말고 시트에 적힌 날짜로 칸을 찾는다. 날짜 키의 뜻을 바꿀 때는 저장된 키도 옮긴다.**
18. ★★ **「수행 평가」가 「수행함 평가」로 바뀐다** → 종결어미 보정 정규식이 문장 중간까지 고쳤다 → **한국어 문체 보정은 문장 끝에서만. 보이지 않는 특수 문자는 이스케이프로 쓰고 회귀 테스트.**
19. ★★★ **내려받은 한글 파일 이름이 「%EC%A0…」로 저장된다** → 서명 URL 라이브러리가 이름을 두 번 인코딩했다. 이미 디코드된 경로 값을 한 번 더 디코드했다 → **인코딩은 정확히 한 번. 파일 이름이 든 다운로드는 실제로 받아서 확인한다.**

91. ★★ **「알림」 꼬리표가 「알/림」 두 줄로 세워진다 / 글씨를 키우자 날짜 칸이 「10.」「12.」「(월)」 세 줄로 쪼개진다** → 좁은 줄의 flex 안에서 꼬리표가 줄어들고, 한글은 글자마다 꺾일 수 있다 → **꼬리표·배지는 `shrink-0` + `white-space: nowrap`. 좁은 날짜 칸은 한 줄 꼴(「10. 12.」)로 쓰고, 글씨 크기를 바꾼 뒤에는 휴대폰 폭 390px에서 다시 본다.**

## 3. Supabase

20. ★★★ **로그인 안 한 방문자가 교직원 명단을 읽는다 / 로그인한 사용자가 뷰를 통해 원래 표를 고치고 지운다** → 뷰는 소유자 권한으로 돌아 RLS를 우회하고, Supabase 기본 권한 때문에 `anon`·`authenticated`에 ALL이 남았다 → **표는 `revoke … from anon, public`, 뷰는 `revoke all … from public, anon, authenticated` 뒤 `grant select … to authenticated`만. 소유자 권한 뷰 안에 `where is_member()`. 익명 거부·뷰 쓰기 거부 테스트.** (2026-10 고침)
21. ★★★ **가드 트리거가 서버 작업까지 막는다 / 정책끼리 무한 재귀** → 시크릿 키로 실행하면 `auth.uid()`가 null이라 `is_admin()`이 false. 정책 안에서 다른 표를 읽으면 재귀 → **트리거에 「`auth.uid()`가 null이면 서버이므로 통과」 분기를 주석과 함께. 재귀는 `security definer` 함수로 끊는다.**
22. ★★★ **화면에 보이는데 「처리」를 눌러도 반영이 안 되고 오류도 없다** → 읽기와 수정 정책의 기준이 달랐다. RLS에 막힌 수정은 「0행 성공」으로 끝난다 → **보이는 것은 고칠 수 있게 두 정책을 맞추고, 반영된 행 수를 확인해 실패를 화면에 띄운다.**

24. ★★ **upsert가 매번 실패한다(42P10) / 「현재 버전」 전환이 실패한다(23505)** → 부분 유일 인덱스는 upsert 충돌 대상이 못 되고, 행마다 즉시 검사한다 → **기존 키를 조회해 넣기/고치기로 나눈다. 「현재 버전」 전환은 SQL 함수 안에서 「끄기 → 켜기」 두 문장으로.**
