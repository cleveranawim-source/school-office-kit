# 키트 업데이트 받기

이 키트는 계속 고쳐진다(새 함정, 더 나은 관문 검사, 새 모듈 안내). 「Use this template」으로 만든 저장소는 원본이 바뀌어도 저절로 따라오지 않으므로, 이 스크립트로 새 판을 받는다.

## 무엇이 바뀌고 무엇이 안 바뀌나

| 바뀌는 것(키트가 관리) | 안 바뀌는 것(우리 학교 것) |
|---|---|
| `kit/` 폴더 전체(문서·양식·스크립트) | 앱 코드 전부 |
| 진행 스킬 `.agents/skills/school-office/`, `.claude/skills/school-office/` | `school-profile.md`, `progress.md`, `docs/design/` |
| `AGENTS.md` 의 키트 구역(`<!-- kit:begin -->` ~ `<!-- kit:end -->`) | `AGENTS.md` 맨 아래 「우리 학교 규칙」 |
| | `README.md`, `CLAUDE.md`, `.gitignore`, 환경변수 |

키트 파일이라도 **선생님(또는 에이전트)이 고친 파일은 덮어쓰지 않는다.** 각 판의 파일 지문 목록(`kit/MANIFEST.json`)과 비교해 「손대지 않은 파일」만 새 판으로 바꾼다.

| 경우 | 하는 일 |
|---|---|
| 손대지 않았고 키트가 바뀜 | 새 판으로 바꿈 |
| 키트에 새로 생김 | 추가 |
| 손대지 않았고 키트에서 빠짐 | 지움 |
| 고쳤고 키트는 그대로 | 그대로 둠 |
| 고쳤고 키트도 바뀜 | 그대로 두고, 새 판을 `파일이름.kit-new` 로 옆에 둠 |

## 순서 (에이전트가 진행)

선생님이 「키트 업데이트해 줘」라고 하면:

1. **지금 작업을 커밋한다.** 업데이트가 마음에 안 들면 그 커밋으로 되돌릴 수 있게. 커밋하지 않은 변경이 있으면 스크립트가 적용을 거부한다.
2. **미리 보기**: `node kit/scripts/update-kit.mjs` — 아무것도 바꾸지 않고, 새 판에서 바뀐 점(CHANGELOG)과 파일별 처리를 보여 준다.
3. **선생님께 요약**: 「새 판(1.2.0)에는 ○○ 함정 3개와 관문 검사 항목이 늘었어요. 우리가 고친 파일 2개는 그대로 두고, 1개는 양쪽이 바뀌어 합쳐야 해요. 적용할까요?」처럼 쉬운 말로.
4. **적용**: 허락을 받으면 `node kit/scripts/update-kit.mjs --apply`.
5. **`.kit-new` 합치기**: 생긴 파일마다 지금 파일과 비교해, 선생님이 고친 내용을 살리면서 새 판의 내용을 들인다. 합친 뒤 `.kit-new` 는 지운다. 판단이 필요한 차이는 선생님께 묻는다.
6. **관문 검사 다시**: `node .agents/skills/school-office/scripts/gate.mjs` — 새 판의 검사 항목이 늘었을 수 있다. 새로 생긴 ❌ 는 다음 단계로 가기 전에 고친다.
7. **커밋**: `키트 업데이트 1.1.0 → 1.2.0`. `progress.md` 「결정 기록」에 한 줄.

## 자주 생기는 일

- **「원본 키트를 가져오지 못했습니다」** — 인터넷 연결을 확인한다. 회사·학교 망에서 GitHub가 막혀 있으면 집에서 한다.
- **스킬을 우리 학교에 맞게 고쳐 썼다** — 그 파일은 「고친 파일」로 남는다. 키트 쪽도 바뀌면 `.kit-new` 가 생기니 합친다.
- **실수로 키트 구역 표시(`kit:begin`/`kit:end`)를 지웠다** — `AGENTS.md.kit-new` 가 생긴다. 표시와 함께 새 구역을 넣고, 우리 학교 규칙은 표시 아래로 옮긴다.
- **업데이트를 되돌리고 싶다** — 1번에서 한 커밋으로 돌아간다(`git reset --hard <그 커밋>` — 선생님 허락을 받고).

## 키트 관리자(원본)가 새 판을 낼 때

1. 고친 뒤 `kit/VERSION` 을 올리고 `kit/CHANGELOG.md` 맨 위에 바뀐 점을 적는다.
2. `node kit/scripts/sync-skills.mjs` (스킬 사본 맞추기)
3. `node kit/scripts/make-manifest.mjs` (지문 목록 새로)
4. 커밋·푸시. `make-manifest.mjs --check` 가 통과해야 한다.
