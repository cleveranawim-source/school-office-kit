# 모듈 카탈로그

원본 학교의 「AI 교무실」 모듈 33개를 정리했다. 모듈마다 **어떤 불편을 덜어 주는지**, **무엇이 먼저 있어야 하는지**, **학교마다 무엇이 다른지**를 적었다.

> 원본 기준: 2026-10-18(커밋 약 1,000개). 1.x판(2026-10-04 기준) 뒤로 모듈 7개가 늘고 넵·수업교체·홈·조직표가 크게 바뀌었다.

- 규모는 원본 학교 코드 기준 대략치다(테스트 제외, 백 줄 단위). 난이도를 가늠하는 데만 쓴다.
- 분류는 다른 학교 기준 제안이다: **핵심**(먼저, 거의 모든 학교) / **추천**(대부분 쓸모) / **선택**(학교 사정 따라).
- 인터뷰에서 선생님이 말한 「불편」을 아래 「덜어 주는 불편」 칸과 맞춰 본다.
- **id**는 `plan.mjs`·`memo.mjs`에 넣는 이름이다(`.agents/skills/school-office/references/modules.json`).
- **함께 손볼 곳**: 모듈 하나를 붙이면 이미 있는 화면도 같이 고쳐야 한다(홈 카드, 현황판 칸, 내 일정 겹치기, AI 도구, 아침 알림 줄). 모듈 절마다 적었고, `memo.mjs`가 설계 메모 5절에 옮긴다. 같은 사실을 여러 화면이 보이면 셈 함수 하나를 같이 쓴다(`06-함정노트.md` 114).

## 핵심

### 앱 틀·공통 부품 — 중

- **덜어 주는 불편**: 여러 도구에 흩어진 학교 일을 휴대폰 한 화면으로.
- **흐름**: 메뉴·하단 탭·디자인 토큰·학교 설정 파일, 서울 날짜 함수, 설정 표, 크론 껍데기, 웹푸시 바탕, 파일 업로드, 기능 문(관리자에게 먼저 보이기). 자세한 것은 `04-뼈대설계.md` 4·5절.
- **1분 틱**: 1분마다 도는 일(넵 배달, 보건실 읽기, 칠판 자동 쪽지, 날씨 안내)이 처음 생길 때 크론 **하나**를 공통 부품으로 만들고, 그 뒤의 일은 모두 그 틱에 얹는다. 일마다 크론을 만들면 호출 수가 늘고, 한 일이 실패해 다른 일을 막는다.
- **학교마다 다른 것**: 학교 이름·약칭·대표 색·학년 수·교시 기본값·근무 시간 — 설정 파일 한 곳에.
- **지킬 것**: 같은 셈(서울 날짜·쉬는 날·조사 고르기)은 함수 하나. 보안 헤더·쓰지 않는 기기 권한 막기(`05-보안기준선.md` C).
- 원본 학교 규모: 약 2,900줄.

### 로그인·계정(휴직 포함) — 중

- **덜어 주는 불편**: 링크만 알면 누구나 보던 자료(패들렛 등)를 교직원만 보게.
- **흐름**: 운영자가 명단으로 계정을 한꺼번에 만든다 → 초기 비밀번호 배부 → 교사는 이름 + 비밀번호로 로그인 → 첫 로그인 때 비밀번호 변경. 명단 밖 교직원(교장·보건 등)은 따로 추가.
- **계정 상태**: 「활동 중 / 휴직 / 비활성」. 휴직은 따로 모듈이 아니라 계정 상태다 — 로그인해서 정해 둔 곳(원본 학교는 자료실 읽기·내려받기·비밀번호 바꾸기)만 쓰고 알림도 받지 않는다. 앱과 DB가 같은 기준(활성 교직원 판별 함수)으로 막는다.
- **데이터**: `profiles`(이름, 부서, 역할, 활성, 휴직, 비밀번호 변경 필요, 호칭), 틀린 횟수 기록(서버만).
- **학교마다 다른 것**: 로그인 방식(이름+비밀번호 / 학교 구글 계정) — `04-뼈대설계.md` 2절. 휴직·파견 교직원을 어떻게 할지(`10-인터뷰.md` 2마당).
- **지킬 것**: 퇴직자는 지우지 않고 비활성화. 비밀번호를 여러 번 틀리면 잠시 막는다. 로그인 토큰이 끝난 뒤 앱을 열어도 튕기지 않게(함정 96). 로그아웃은 전체 새로고침 이동. → `05-보안기준선.md` F
- 원본 학교 규모: 약 1,000줄.

### 관리 (관리자만) — 중

- **덜어 주는 불편**: 학기마다 바뀌는 값(교시 시각, 담임, 외부 링크, 안내문)을 바꿀 때마다 코드를 고쳐야 하는 일.
- **흐름**: 교사 관리(추가·비밀번호 초기화·역할·부서·휴직/복직·비활성화), 시간표 업로드, 설정 카드(쓰는 모듈마다 하나), AI 평가 보기.
- **데이터**: `settings`(키-값), `profiles`, `homerooms`.
- **지킬 것**: 설정 표는 교사가 읽지 못하게. 비밀 주소(캘린더 비공개 주소, 시트 토큰)는 화면 밖으로 새지 않게.
- 원본 학교 규모: 약 1,900줄(설정 카드 13개).

### 급식 — 하

- **덜어 주는 불편**: 급식 메뉴 찾아보기. 아침·점심 알림에 함께 실려 체감이 크다.
- **흐름**: 이번 주 중식 메뉴(알레르기 번호 포함)를 주 단위로 넘겨 본다. 주말에는 다음 주.
- **데이터**: 표 없음. 나이스 교육정보 개방 포털의 급식 API를 6시간 캐시.
- **학교마다 다른 것**: 교육청 코드·학교 코드 두 개뿐. **가장 옮기기 쉬운 모듈**이라 첫 성공 경험으로 좋다.
- 원본 학교 규모: 약 300줄.

### 공지 — 하~중

- **덜어 주는 불편**: 메신저 쪽지에 묻혀 사라지는 전체 공지.
- **흐름**: 관리자가 공지(첨부 3개, 링크 5개)를 올린다. 고정하지 않은 공지는 24시간 뒤 목록에서 내려가고, 30일 뒤 첨부까지 지운다. **전체 푸시는 알림(4단계)을 붙일 때 잇는다** — 그 전에는 홈·목록에서만 보인다.
- **현황판을 만들면**: 공지는 따로 메뉴를 두지 않고 현황판 맨 위 「공지판」으로 옮긴다(원본 학교). 홈의 공지 칸도 「오늘 알림」 한 칸으로 합친다.
- **데이터**: `notices`, 비공개 버킷.
- **지킬 것**: 보존 기한 숫자가 코드·DB 정책·목록 질의 세 곳에 있으면 함께 바꾼다. 첨부 경로는 경로 검사 함수로(함정 93). 잘못 보낸 전체 푸시는 거둘 수 없다(함정 100).
- 원본 학교 규모: 약 1,200줄.

### 홈 — 중

- **덜어 주는 불편**: 아침마다 여러 곳을 열어 보던 일 — 「오늘 무엇이 있나」를 한 화면에.
- **흐름(원본 학교)**:
  - 맨 위: 날짜·날씨, 상황에 맞춘 한마디(쉬는 날·행사·비·수업 많은 날·내 출장 등. 규칙으로 고르고, 원하면 AI가 짧게 쓴다 — 실패하거나 늦으면 규칙 문장), 그 아래 정보 문장(수업 N시간·첫 일정).
  - 숫자 칸: 「일정」·「현황판」. 누르면 나오는 화면과 같은 셈이다.
  - 「오늘 알림」: 공지 몇 줄 + 오늘 바뀐 수업 + 오늘 마감 넵 + 특별 일정. 하나도 없으면 다정한 한 줄.
  - 오늘 시간표(지금 교시 「지금」, 쉬는 시간엔 「다음」, 교체·일정 표시), 처리할 넵 N건, 급식, 다가오는 일정 7일.
  - 오른쪽 위 종(알림함). 행사가 있으면 행사 카드, 관리자가 보낸 축하 한 줄(받는 분 홈에만).
- **학교마다 다른 것**: 학교 관행에 맞는 줄(아침 모임 담당·등교 지도 교사 같은 학교 문화), 날씨를 넣을지(공공데이터 열쇠·학교 위치).
- **지킬 것**: 날씨 같은 부가 정보를 기다리지 않는다(짧게 기다리고 늦으면 빼고 그린다). 조회마다 대체값을 두어 하나가 실패해도 화면이 뜬다. 사유(출장·연수)는 **본인 것만**. 다그치거나 「퇴근했다」고 단정하는 말은 넣지 않는다. AI 인사는 상투어를 거르고 실패하면 규칙 문장으로(함정 106).
- **함께 손볼 곳**: 다른 모듈이 생길 때마다 카드·숫자 칸이 늘어난다. 처음엔 껍데기(오늘 날짜·급식·공지)로 시작한다.
- 원본 학교 규모: 약 2,300줄(학교 관행 줄·행사·축하 카드 포함).

### 시간표 — 중

- **덜어 주는 불편**: 시간표 엑셀을 휴대폰으로 열어 확대해 보던 일. 「지금 빈 교실·빈 선생님」 찾기.
- **흐름**: 관리자가 시간표 파일을 올림 → 변환 미리보기(통계·경고·계정 없는 교사) → 적용. 교사는 교사/학급/교실/전체 탭으로 보고, 지금 교시가 강조된다. 「공강인 선생님」 이름을 누르면 그분과의 넵 대화로 간다(넵이 있을 때).
- **데이터**: `timetable_versions`(JSON, 현재 판 하나), 설정 `period_times`(교시 시각).
- **학교마다 다른 것 — 가장 크다**: 시간표 프로그램의 내보내기 형식이 학교마다 다르다. **변환기는 새로 쓴다.** 인터뷰 때 받은 시간표 파일 하나(실명 지운 것)로 시작하고, 변환 결과를 손으로 대조하는 테스트를 둔다. 나이스 공개 API의 시간표로 대신할 수 있는지도 확인해 본다.
- **지킬 것**: 「현재 시간표」는 언제나 하나(SQL 함수로 원자적 전환). 교사는 이름으로 맞추므로 동명이인 주의.
- **중요**: 진도표, 넵 배달, 보건 알림, 칠판 쉬는 시간 잠금, 홈, AI가 모두 「지금 수업 중인가」를 여기서 묻는다. 단축 수업·교체가 있는 날의 「그날 실제 시간표」는 아래 **그날 시간표**가 맡는다.
- 원본 학교 규모: 약 1,600줄.

### 일정 — 중

- **덜어 주는 불편**: 학사일정 엑셀과 캘린더를 따로 보던 일.
- **흐름**: 관리자가 구글 캘린더 주소(ICS)를 넣고 동기화. 화면을 열 때 1시간 지났으면 다시 읽는다(크론 불필요). 공휴일 캘린더도 함께. 관리자 직접 입력 가능. 달력·주간 목록·고른 날 목록.
- **내 것만 겹쳐 보이기**: 넵 마감, 내 수업교체 사유, 교체로 맡은 수업은 **보는 사람의 일정에만** 겹쳐 보인다. 학사일정 표와 구글 캘린더에는 넣지 않는다.
- **데이터**: `events`(출처: 직접/캘린더/공휴일, 외부 id).
- **학교마다 다른 것**: 일정을 어디서 관리하는지(구글 캘린더 / 나이스 학사일정 / 엑셀) — 출처별 읽기 부분만 바꾼다. 학교 달력에 쉬는 날·교시를 적는 표기(「재량휴업일」, 제목 끝 교시 숫자 등) — 실제 제목을 표로 시험한다.
- **지킬 것**: 비공개 캘린더 주소는 비밀. 가져오기 실패 시 기존 일정을 그대로 둔다. 종일 일정은 서울 자정 기준(`06-함정노트.md` 12). **쉬는 날 판정은 함수 하나**를 홈·현황판·알림·배달·주간소식이 같이 쓴다(16).
- 원본 학교 규모: 약 1,700줄.

### 담임 배정 — 하

- 관리 > 설정에 「2-3 홍길동」처럼 한 줄씩. 결석 접수·보건 알림·칠판 「내 반」·행사 알림·AI 도구가 쓴다. 독립 화면 없이 관리 카드 하나로 시작한다.
- **지킬 것**: 반 이름이 시간표·칠판 교실 이름과 **같은 글자**여야 한다(「1-3」). 다르면 칠판 「내 반」과 담임 알림이 조용히 빠진다.
- 원본 학교 규모: 약 60줄.

### 자료실 — 중 (AI 색인까지 하면 상)

- **덜어 주는 불편**: 패들렛·밴드·공유 폴더에 흩어진 양식, 권한·검색이 약한 자료 게시판.
- **흐름**: 교사 누구나 링크·파일(20MB 이하)·글을 올린다. 부서 섹션과 검색으로 찾는다. 링크는 앱 안 보기 화면으로 연다(보기 화면 주소에는 바깥 주소를 싣지 않는다 — 함정 4). 관리자는 고정·공개 범위(관리자만)·「AI가 읽지 않음」을 정한다. 휴직 교직원도 읽을 수 있는 곳으로 둘 수 있다.
- **데이터**: `library_sections`, `library_posts`, `library_texts`(AI 색인), 비공개 버킷.
- **학교마다 다른 것**: 부서 섹션 목록, 기존 자료가 있는 곳(→ 이관 스크립트를 그에 맞게 새로).
- **지킬 것**: 파일은 서명 주소로 직접 업로드. 시크릿 키로 서명하기 전에 경로 검사 함수(93). 고정·공개 범위는 트리거로 관리자만. 민감 자료(계정 정보, 학생 명렬표)는 관리자만 + AI 제외. 옮겨 오는 기존 도구와 **한 학기 병행**.
- 원본 학교 규모: 약 2,900줄(색인·이관 포함).

### 알림(웹푸시) — 중

- **덜어 주는 불편**: 아침마다 화면을 열어 확인하던 일. 이후 모든 즉시 알림(넵·결석·보건·서명)의 통로가 된다.
- **흐름**: 교사가 기기마다 「알림 켜기」(아이폰은 홈 화면 추가가 먼저). 평일 아침(07:50)·점심(11:30) 요약 푸시 — 원본 학교는 사람마다 **「내 줄」**을 맨 위에(내 당번 → 바뀐 내 수업 → 내 수업 시간과 겹치는 일정 → 오늘 마감), 그 아래 공통 줄. 누르면 그 화면으로. AI가 있으면 「나와 관련된 일정」을 골라 넣고(`07-AI도우미.md` 11절), 금요일 오후 「다음 주 미리 보기」를 더할 수 있다.
- **데이터**: `push_subscriptions`, 설정(마지막 실행·결과·시험 잠금 — 모든 발송을 한 사람에게만 보내는 시험 스위치).
- **학교마다 다른 것**: 요약에 넣을 내용(지도 교사 순번 등이 학교 시트에 있으면 그 파서), 알림 시각.
- **지킬 것**: 하루 한 번 보장(보내기 전 선점), 죽은 구독 정리, 활성 계정만(휴직 제외), 쉬는 날 쉼, 시험 잠금. 여러 사람이 보는 요약에는 결강·부재 **사유를 싣지 않는다**. → `06-함정노트.md` 5절
- **함께 손볼 곳**: 공지(전체 푸시 잇기), 홈.
- 원본 학교 규모: 약 1,800줄.

### 알림함 — 하~중

- **덜어 주는 불편**: 푸시는 한 번 뜨고 사라진다. 놓친 알림을 다시 볼 곳이 없다.
- **흐름**: 홈 오른쪽 위 종. **나에게만 온** 알림 가운데 확인하지 않은 것을 모아 둔다. 눌러 그 화면으로 가거나 「확인」·「모두 확인」을 누르면 지우고, 남아 있는 동안 종에 빨간 점. 다시 볼 요약(다음 주 미리 보기 같은 것)은 눌러도 남기고 「확인」으로만 지운다.
- **데이터**: `notifications`(받는 사람, 제목, 이동할 주소, 만든 때). 확인하지 않은 채 30일 지나면 크론이 지운다.
- **지킬 것**:
  - 개인 알림은 **함수 하나**(`notifyUsers`)를 지난다 — 비활성·휴직을 빼고 시험 잠금을 지킨 뒤, 푸시와 알림함을 같이 남긴다(`04-뼈대설계.md` 5절).
  - 특정 글을 가리키는 알림을 만들면 그 표에 **지우기 트리거**도 건다. 글을 지웠는데 알림이 남으면 누를 때 흰 화면이 뜬다(함정 102).
  - 끝난 할 일 알림(예: 「초안이 준비됐습니다 — 발행해 주세요」)은 일이 끝나면 지운다.
  - 모두에게 가는 공지·요약은 넣지 않는다.
- 원본 학교 규모: 약 400줄. 알림(웹푸시)과 같은 단계에 만드는 편이 싸다 — 뒤에 붙이면 모듈마다 보내는 곳을 다시 고친다.

## 추천

### 그날 시간표(학사일정·교체 얹기) — 중

- **덜어 주는 불편**: 기본 시간표만 보여서, 단축 수업·요일 바꾸기·수업 교체가 있는 날 「오늘 내 수업」과 빈 교실이 틀린다. 「내일 출장인데 홈이 수업 3시간이라고 한다」.
- **흐름**: 기본 시간표 위에 ① 그날 학사일정의 시정 변경(「N교시까지」, 요일 바꾸기, 학년 행사로 그 학년 수업 없음, 쉬는 날) ② 수락이 끝난 수업교체를 얹은 「그날 실제 시간표」를 함수 하나로 만든다. 홈 「수업 N시간」·오늘 시간표 카드, 시간표 화면, 진도표 「오늘 적기」 칸, 빈 교실·공강 찾기가 모두 이것을 쓴다. 시간표 칸에는 수업 시간과 겹치는 일정을 띠로 붙인다.
- **데이터**: 새 표 없음(시간표·일정·교체에서 셈).
- **학교마다 다른 것**: 학교 달력에 시정 변경을 적는 표기가 학교마다 다르다. 실제 달력 제목을 표로 시험하고, 교시를 정할 수 없는 일정은 「확인 필요」로 남긴다.
- **지킬 것**: 수락을 기다리는 교체는 얹지 않는다. **다른 선생님 개인 시간표에는 교체·부재를 얹지 않는다**(누가 자리를 비우는지 드러난다). 학급·교실 칸에는 선생님 이름을 싣지 않는다(학생이 본다). 함수 하나 — 화면마다 다시 세면 숫자가 어긋난다(114).
- **함께 손볼 곳**: 시간표, 홈, (있으면) 진도표.
- 원본 학교 규모: 약 600줄. 원본 학교도 처음엔 기본 시간표만 썼고, 수업교체를 사이트 안에 들인 뒤 이 층을 따로 뗐다.

### 현황판 — 중

- **덜어 주는 불편**: 「오늘 평소와 달라진 것」(공지·바뀐 수업·특별 일정·내 마감)을 알려면 여러 곳을 열어야 한다.
- **흐름(원본 학교)**: 맨 위 공지판(공지 — 고정 + 올린 지 하루 안, 관리자는 여기서 「공지 쓰기」) → 그날 「내 넵」(넵 마감 + 넵 속 일정) → 특별 일정(학사일정 + 발행된 주간소식 항목) → 바뀐 수업(맨 아래). 날짜를 골라 볼 수 있고, 알림을 누르면 그날로 연다. 열어 두면 1분마다 새로 읽는다. 원본 학교는 화면에 학교에서 부르기 쉬운 별명을 붙였다.
- **데이터**: 바뀐 수업은 수업교체에서 읽는 **뷰**(필요한 열만 — 반·교시·과목·「내 것인가」).
- **학교마다 다른 것**: 보일 것과 보이면 안 되는 것. 바뀐 수업에 선생님 이름을 보일지(원본 학교는 과목만 — 「2-3반 · 과학 → 수학」). 수업교체가 없으면 공지·특별 일정·내 마감만으로 시작한다.
- **지킬 것**:
  - 누가 왜 자리를 비우는지(출장·연수·부재의 **사유**)는 화면에도 뷰에도 싣지 않는다. 화면에서 감춰도 뷰가 이름 열을 내보내면 브라우저에서 데이터 API로 읽힌다(함정 92) — RLS 테스트에서 뷰를 직접 불러 열을 확인한다.
  - 수락을 기다리는 교체는 「수락 대기」로 표시하되, 학생이 보는 곳(교실 칠판)과 홈 건수에는 수락이 끝난 것만.
  - 현황판·홈·아침 알림의 「바뀐 수업」 건수는 같은 함수로.
- **함께 손볼 곳**: 공지(공지판으로 옮기기), 홈(공지 칸 → 「오늘 알림」).
- 원본 학교 규모: 약 700줄.

### 진도표 — 하~중

- **덜어 주는 불편**: 반마다 어디까지 나갔는지 기억에 의존. 대신 들어간 수업에서 그 반 진도를 모름.
- **흐름**: 「오늘 적기」에 그날 내 수업마다 한 줄 — 하루치를 화면 아래 「모두 저장」 하나로 저장(고친 칸만 보낸다). 그날 시간표가 있으면 칸이 그날 실제 수업(교체로 들어온 수업은 「바뀜」). 「이 반 진도」는 그 반을 가르치는 교사들의 기록을 모아 보이고, 그 반 교사끼리만 본다. 「진도 지도」(반×주 격자)는 넓은 화면에서만, 휴대폰은 한 주씩 넘기기. AI가 있으면 「진도 보여 줘」는 읽기 도구로, 「오늘 3반 2단원 적어 줘」는 확인 카드로.
- **데이터**: `lesson_logs`(교사·날짜·교시 유일).
- **학교마다 다른 것**: 거의 없다.
- **지킬 것**: 진도 지도는 **본인 것만**, 관리자도 남의 지도를 못 연다. 손대지 않은 칸은 다른 기기에서 고친 것을 덮지 않는다. 저장 안 한 칸이 있으면 다른 화면으로 갈 때 한 번 묻는다.
- 원본 학교 규모: 약 1,700줄.

### 조직표·받는 사람 고르기 — 중

- **덜어 주는 불편**: 「교무부에게」, 「부장단에게」 보내기가 안 된다. 수십 명 가운데 받는 사람을 고르기 어렵다.
- **흐름**: 학기마다 업무분장·명렬표 파일을 넣어(미리 보기 → 적용) 부서·학년부·교과·직책을 채운다. 그 위에 **받는 사람 고르기 부품 하나**(조직도 나무)를 둔다 — 찾기 칸(이름 일부·초성), 칩(나·교직원 전체·부장단·교과 주임단), 최근 보낸 분, 관리자 직함(교장·교감), 접힌 부서와 「교과별」. 부서를 통째로 체크하면 묶음으로, 한 분이라도 빼면 남은 분 이름으로 풀린다. 넵·서명부·파일 서명이 이 부품을 같이 쓰고, 넵은 이것으로 묶음 대화방을 정한다.
- **학교마다 다른 것**: 업무분장 파일 형식(→ 파서를 새로 쓰거나 관리 화면에서 직접 입력), 학교가 쓰는 묶음 이름.
- **지킬 것**: 명렬표의 연락처·내선은 읽지도 저장하지도 않는다. 원본 파일은 저장소에 넣지 않는다. 휴직·비활성 교직원은 고르기에서 뺀다. 연락처·접속 상태는 고르기에도 싣지 않는다.
- 원본 학교 규모: 약 600줄(고르기 부품 포함).

### 넵(업무 메신저) — 상

- **덜어 주는 불편**: 메신저 업무방은 누가 읽었는지·끝냈는지 모른다. 지시가 대화 아래로 묻힌다. 첨부를 다시 요청하는 일이 반복된다. 수업 중·퇴근 뒤에도 울린다.
- **흐름(원본 학교)**: 처음엔 「업무 요청」(보내기 화면 + 현황)으로 시작해, 자리 잡은 뒤 **메신저 업무방을 옮기는 업무 메신저**로 키웠다.
  - 첫 화면은 대화 목록: 위 「답할 것 · 마감 가까운 순」, 아래 「그 밖의 대화 · 최근 순」. 넓은 화면은 왼쪽 목록·오른쪽 방.
  - 방: 한 분이면 1:1, 「나에게」, 묶음(전체·부서·교과·부장단)이면 그 묶음 방. 보낸 분이 그 묶음 식구가 아니면 받는 분은 보낸 분과의 1:1 방에서 본다(「전송은 한꺼번에, 대답은 개인으로」). 새 대화는 「+」 → 받는 사람 고르기.
  - 종류(화면 이름): **메시지**(표시 없음) · **넵 받기**[넵] · **완료 받기**[완료] · **파일 받기**[제출]. 받는 사람은 단추 **하나만** 누른다. 입력줄 「+」에서 고르고, 마감·예약·긴급을 붙인다(글 속 날짜로 마감 처음 값을 채우되, 보내기 전에 보이는 이름표로).
  - 내가 보낸 말풍선에는 안 읽은 수, 답 받기에는 처리 막대. 누르면 「아직 N명」·[다시 알림](하루 1회)·파일 「모두 받기」(브라우저에서 zip).
  - 길게 눌러 **답장** — 원래 보낸 분 한 분에게만 간다.
  - 마감과 넵 속 일정(AI가 보낼 때 글에서 읽어 둔 날짜·교시)은 보낸 분과 배달된 받는 분의 **일정·현황판·홈에만** 겹쳐 보인다.
  - 글씨 크기 단추(보통·크게·아주 크게, 이 기기에 기억).
- **배달 규칙**: 받는 사람 기준 — 수업 중이면 교시 끝에, 근무 시간 밖이면 다음 근무일 아침에, 긴급만 즉시(월 한도). 메시지 한 줄도 같다. 배달 전이면 말풍선에 「10:40 도착」.
- **데이터**: `neps`(종류·받는 사람·마감·답장 대상), `nep_receipts`(배달 시각·읽음·완료·제출물·다음 리마인드), 넵 속 일정, 1분 틱.
- **학교마다 다른 것**: 근무 시간, 긴급 한도, 몇 명 넘으면 한 번 더 물을지, 보존 기한(원본 학교: 글은 학년도 끝까지, 첨부 파일은 닫힌 지 90일). 메신저 업무방을 옮길지 — 옮긴다면 메신저만큼 편해야 한다. 부서·학년 대상 발송은 **조직표가 채워져 있어야** 한다(원본 학교는 처음에 70여 명 중 10명만 부서 값이 있었다).
- **지킬 것**:
  - 배달·리마인드 규칙은 순수 함수 하나가 정본이고 테스트로 지킨다. 판정 기준 「근무 시간 밖에 도착한 알림(긴급 제외) 0건」.
  - 받는 사람은 남의 처리 기록을 못 본다. 답장은 묶음의 다른 분에게 안 보인다(RLS 테스트).
  - 마감·넵 속 일정은 학사일정 표·구글 캘린더에 넣지 않는다.
  - 처리 안 한 오래된 넵이 목록·홈 숫자에서 빠지지 않게, 한 번에 읽는 범위를 「처리 안 한 것 전부 + 최근 N건」으로(함정 95).
  - 여러 명(원본 학교: 20명 이상)에게 가는 발송은 보내기 전에 받는 분·마감을 한 번 더 보인다 — 푸시는 거둘 수 없다(100).
  - 새 실시간 통로는 만들지 않는다(보낸 뒤·돌아올 때·방이 열려 있으면 1분마다 다시 받기 — 비용).
- **함께 손볼 곳**: 홈(처리할 넵 N건·오늘 마감), 일정(내 넵 겹치기), 현황판(내 넵 칸), AI 도우미(넵 읽기 도구, 넵 초안 확인 카드 — AI는 바로 보내지 않는다), 아침 알림(오늘 마감 줄).
- 원본 학교 규모: 약 4,100줄. 배달 엔진을 먼저 순수 함수 + 테스트로 만든다. 메신저 모양은 그 뒤에.

### 주간소식 — 중

- **덜어 주는 불편**: 교무부 주간 일정 PDF를 각자 열어 보던 일.
- **흐름**: 주간 일정표·월 주요일정은 일정 모듈에서 자동, 부서 알림·안내문만 관리자가 적는다. 매주 같은 안내는 「상시 안내」에 한 번. 「발행」을 눌러야 보이고 푸시가 나간다. 원본 학교는 화면을 학교 PDF와 같은 짜임(「월/일 │ 내용」 표 → 공지사항 → 안내문)으로 맞췄다.
- **이어지는 곳**: 발행된 소식의 날짜별 항목을 현황판 「특별 일정」·시간표 칸·홈 오늘 시간표에도 붙인다(같은 일정은 한 번만).
- **학교마다 다른 것**: 원본 학교는 공유 드라이브의 PDF를 크론이 읽어 초안을 만들고, AI에 PDF를 붙이면 초안 카드도 만든다. 다른 학교는 **수동 입력판부터** 시작하고, 자동 초안은 나중에.
- **지킬 것**: 발행한 호는 자동 초안이 덮어쓰지 않는다. 발행은 사람이 눈으로 보고. 「다시 발행」해도 모두에게 알림을 또 보내지 않는다(함정 101).
- **함께 손볼 곳**: 현황판, 그날 시간표, AI 도우미.
- 원본 학교 규모: 약 1,400줄.

### 내 서명 — 중

- 손 서명(그리기)과 도장(사진에서 바탕 지우기)을 등록해 기본 하나를 정한다. 서명 모듈·수업교체의 기반.
- **지킬 것**: 본인 서명만 읽는다(관리자도 못 봄). 파일은 서버만 올리고, PNG 형식·크기 검사. 바꿀 때마다 새 경로에. 올라오는 창 안의 그리기 판은 창이 열린 뒤 크기를 잰다(함정 87).
- 원본 학교 규모: 약 800줄.

### 서명 (회의 서명부·파일 서명) — 상

- **덜어 주는 불편**: 종이 서명부 돌리기. 서명 받을 일이 생길 때마다 새 기능을 만드는 일.
- **흐름**: 회의 서명부 — 회의명·일시·참석자(받는 사람 고르기 부품) → 알림 → 참석자가 [내 서명으로 서명] 한 번 → A4 PDF. 파일 서명 — 서식 파일(PDF·hwpx)을 올리면 `(서명)`·`(인)` 자리를 찾아 주인을 정하고, 각자 서명하면 원래 형식 그대로 서명된 파일.
- **지킬 것**: 본인이 누를 때만 서명이 들어간다. 서명 순간의 사본을 문서 쪽에 남긴다. 완성 파일은 요청자·관리자만. 전자결재를 대신하지 않는다.
- 회의 서명부부터, 파일 서명은 나중에. 원본 학교 규모: 약 2,100줄.

### AI 도우미 — 상

→ `07-AI도우미.md`. 읽을 모듈이 몇 개 생긴 뒤에 붙인다. **읽기 도구부터**, 확인 카드는 나중에.

- 원본 학교는 7주 동안 도구가 33개(공유 드라이브 3개 포함)로 늘었다: 모듈마다 읽기 도구, 넵·진도표·분실물·수업 자료·주간소식 초안 같은 확인 카드, 붙인 파일·주소 읽기, 공유 드라이브 읽기(선택), 매일 알림에 「나와 관련된 일정」 고르기, 홈 인사.

- 원본 학교 규모: 약 9,400줄(점검 세트·드라이브 읽기 포함).

- **덜어 주는 불편**: 구글 시트 십여 개에 흩어진 신청(가정통신문 번호, 기기 수리, 특별실 예약, 희망도서) — 매번 시트를 찾아 칸에 적기.

- 원본 학교 규모: 약 600줄.

## 선택

### 결석 접수 — 중

- **덜어 주는 불편**: 전화·문자로 흩어진 결석 연락, 손으로 쓰는 출결 신고서.
- **흐름**: 보호자가 카카오톡 채널에 「결석」 → 학반·이름·종류·날짜·사유를 대화로 → 답장, 볼 수 있는 선생님께 푸시 → 처리 상태를 바꾸고 출결 신고서(hwpx)를 받는다.
- **볼 수 있는 사람**: 「그 반 담임과 관리자」 또는 「관리자만」. 원본 학교는 운영 방식을 정하는 동안 **스위치 하나**로 관리자만 보게 했다 — 메뉴·목록·AI 도구·새 접수 알림·학부모 답장 문구(담임 이름 대신 「담당 선생님께 전달됩니다」)가 모두 그 값을 따르고, DB 권한(담임 + 관리자)은 그대로 둔다. 다시 열 때는 값 하나만.
- **학교마다 다른 것**: 학부모 창구(카카오 채널 운영 여부, 다른 앱), 출결 서식, 누가 볼지(`10-인터뷰.md` 2마당). 봇의 두뇌(대화 흐름)를 메신저와 분리해 두면 창구를 바꾸기 쉽다.
- **지킬 것**: 카카오 5초 제한(`06-함정노트.md` 62). **건강 정보가 담기므로 지난 학년도 접수는 4월에 자동 삭제.** 접수를 지우면 그 접수를 가리키던 알림도 지운다(102).
- 원본 학교 규모: 약 900줄.

### 체험학습 신청 — 하~중

- 결석 접수와 같은 봇에 얹는다. 기간·장소·목적·계획·보호자·인솔자를 받아 학교 신청서 서식을 채운다. 볼 수 있는 사람·보존은 결석 접수와 같은 스위치·규칙. 원본 학교 규모: 약 500줄.

### 보건실 — 하~중

- **덜어 주는 불편**: 학생이 보건실에 간 줄 몰라 결석으로 오해하거나 찾아다니는 일.
- **흐름(원본 학교)**: 학교가 쓰는 보건실 프로그램의 「담임 공유」 화면을 새 창으로 열고, 1분 틱이 공유 자료를 읽어 새 입실을 담임과 그 교시 교과 교사에게 푸시.
- **학교마다 다른 것**: 보건실 프로그램. 공유 기능이 없으면 이 모듈은 빼는 것이 낫다.
- **지킬 것**: 학교 관행(반·성별만)보다 더 기록하지 않는다. 교과 교사에게는 수업 중·시작 5분 안 입실만.
- 원본 학교 규모: 약 300줄.

### 교실 칠판 알림 — 상

- **덜어 주는 불편**: 반에 전할 말이 있으면 전화하거나 사람을 보내던 일. 재난 때 방송이 닿지 않을 경우의 두 번째 통로.
- **흐름**: 교사가 무엇을(안내·쪽지·긴급, 링크·사진·예약) → 어디에(내 반·학년·전체·직접 고르기) 보낸다. 교실 칠판은 로그인 없이 교실별 토큰 주소를 전체화면으로 열어 둔다. 안내는 칠판 터치로 확인, 긴급은 보낸 사람이 종료.
- **원본 학교가 더한 것(골라 쓴다)**:
  - 쪽지(귀퉁이 짧은 글), 예약(오늘·내일), 링크 영상 재생, 음성 안내(30초, 하루 뒤 파일 삭제).
  - 시험 날 화면: 학년별 시험 시간표·끝까지 남은 시간·반 재적/결시(담임이 입력).
  - 수업 중에는 안내를 숨겼다가 쉬는 시간에 다시(윈도우 칠판 창 프로그램).
  - 자동 쪽지: 아침 「오늘 바뀐 수업」(수업교체), 날씨 안내 — 이름표는 서버만 단다.
  - 관리자의 안내만 「공지사항」 이름으로 보낼 수 있다.
- **학교마다 다른 것**: 칠판 기종·운영체제, **학교 보안점검 기준**(화면보호기·잠금). 원본 학교는 윈도우용 작은 프로그램(화면보호기·칠판 창)까지 만들었다. 다른 학교는 **크롬 키오스크 + 웹 화면만으로** 시작한다.
- **지킬 것**: 토큰이 곧 열쇠 — 교사 화면·응답·알림·실시간 채널 이름에 싣지 않는다(`05-보안기준선.md` E). 폴링 간격 정책(무료 한도 초과 사례 — 함정 42). 쉬는 시간 잠금. 사람이 보낸 안내가 자동 알림 이름표를 달 수 없게 DB가 막는다(109). 긴급은 보내기 전에 대상·곳 수·꺼진 칠판을 보이고 한 번 더 묻는다. 학생 이름이 남을 수 있어 7일 뒤 삭제.
- 시작 전에 학교 정보 담당과 교실 PC 설정을 상의한다. 원본 학교 규모: 약 5,700줄(윈도우 프로그램 포함).

### 세특 도우미 — 상

- **덜어 주는 불편**: 과세특·동아리·행발 초안 작성, 나이스 엑셀 왕복.
- **흐름**: 나이스 내보내기 엑셀을 올리고 활동 기록으로 학생마다 초안을 만들고, 검증(분량·금지어)을 거쳐 지정한 열만 채운 엑셀로 내려받는다.
- **지킬 것**: **학생 이름을 프롬프트에 넣지 않는다.** 학생 기록을 서버에 남기지 않는다(브라우저에만). 교사 개인 API 키를 받는다면 `05-보안기준선.md` H.
- **학교마다 다른 것**: AI 비용 주체(학교 키 / 교사 개인 키), 그 해 기재요령.
- 원본 학교 규모: 약 4,600줄.

### 수업교체 — 중~상

- **덜어 주는 불편**: 교체를 사람이 맞춰 보고 신고서를 손으로 쓰던 일.
- **흐름(원본 학교)**:
  - 계산: 교체 조건(선생님·날짜·교시·사유)을 넣으면 교체안이 나온다. 교체를 계산하는 따로 있는 도구(원본 학교는 다른 교사가 만든 계산기)를 연결하거나, 사이트 안에 들인다. 원본 학교는 처음엔 화면 안에 띄웠다가 나중에 사이트 안에 들였다. 갚는 수업 날짜는 「그 주·한 주 뒤·두 주 뒤」에서 고르고, 막힌 날은 이유와 함께 고를 수 없다.
  - 요청 → 상대 수락(=서명) → 교무부 제출함 → 확인 → 신고서(hwpx).
  - 교무부 직접 등록: 종이로 받은 교체를 제출함에 바로 넣는다(대신 들어감·맞바꿈·보강 필요).
  - 교실 정하기: 들어오는 수업의 교실이 그 시간에 차 있으면 「교실 배정 필요」로 붙이고, 제출함에서 그날 빈 교실을 고른다.
  - 고치기: 등록한 교체를 등록 화면으로 되돌려 고치고, 바뀐 칸에 걸린 선생님께만 알린다.
  - 관리자 대신 수락: 사이트를 쓰지 않는 선생님은 구두로 동의를 받고 관리자가 누른다(서명 칸은 글자로).
  - 이미 잡힌 교체를 계산 전에 얹고, 제출함에 겹침을 보인다.
- **다른 학교에서는**: 교체 규칙이 학교마다 달라 가장 학교 특수다. **처음엔 신고서 채우기 + 상대 수락만** 두고, 계산은 나중에(따로 있는 도구를 연결하거나 이 학교 규칙으로). 학사일정(단축·행사)을 계산에 반영한다면 학교 달력 표기를 표로 시험한다. 시간표는 사이트 것 하나만 쓴다(두 벌이 되지 않게).
- **학교마다 다른 것**: 신고서 서식, 교무부가 직접 등록할지, 화면에 쓸 낱말(원본 학교는 화면·알림·AI 답에 「결강」 대신 「수업 교체」).
- **지킬 것**: 요청·수락·확인은 언제나 사람이 단추로. 상태는 조건부 갱신으로 한 번만. **사유는 본인 화면(내 일정·홈)에만** — 현황판·다른 선생님 화면·아침 알림·교실 칠판에는 싣지 않는다(`05-보안기준선.md` G). 아이폰 날짜 칸 모양(함정 88).
- **함께 손볼 곳**: 그날 시간표(교체 얹기 → 시간표·홈·진도표가 함께 바뀜), 현황판(바뀐 수업), 홈(맡아 준 수업·내 사유), 일정(내 사유·맡은 수업을 나에게만), 교실 칠판(아침 바뀐 수업 쪽지), AI 도우미(교체 계산 도구 — 교체 화면과 같은 함수).
- 원본 학교 규모: 약 3,700줄(옮겨 온 계산기 코드는 빼고 셈).

### 교과협의록 — 하~중

- 이미 쓰는 협의록 앱이 있으면 화면 안에 띄운다(iframe, 만든 분의 동의). 없으면 자체 표나 문서 링크로 시작한다. 회의 서명부와 이어 붙일 수 있다. 원본 학교 규모: 약 300줄.

### 분실물 함 — 중

- **덜어 주는 불편**: 교무실에 쌓인 분실물의 주인을 찾기 어렵고, 누가 언제 돌려줬는지 모른다.
- **흐름(원본 학교)**: 교사 누구나 「분실물 넣기」로 사진·종류·발견 장소·보관 장소·특징(주인 확인용)을 올린다. 함 화면은 보관 중인 물건 사진을 모아 보이고, 누르면 상세 → 「주인에게 돌려줬어요」(바로 되돌리기, 「돌려준 물건」 목록에서 다시 넣기). AI가 있으면 사진을 붙여 「함에 넣어 줘」를 확인 카드로.
- **학생용 보기 — 기본 꺼짐**: 로그인 없는 열쇠 주소(학생이 휴대폰으로 보는 목록)와 교실 칠판의 분실물 띠는 처음에 끈다. **켜기 전에 교육청·학교 지침을 확인한다.** 켜면 허용한 칸(사진·종류·발견 장소·날짜·보관 장소)만 — 주인 확인용 특징과 넣은·돌려준 선생님은 싣지 않는다(`05-보안기준선.md` E, 함정 78).
- **데이터**: 분실물 표(넣은 사람·돌려준 사람·시각), 비공개 사진 버킷.
- **지킬 것**: 사진은 휴대폰에서 다시 그려 올린다 — 찍은 곳(위치 정보)이 빠지고 크기가 준다(110). 사진 경로는 정해진 모양만(93). 넣기·돌려줌은 서버 동작으로만.
- **함께 손볼 곳**: AI 도우미(넣기·돌려줌 카드), 교실 칠판(학생용을 켤 때만 띠).
- 원본 학교 규모: 약 900줄.

### 학생 사진 명렬표 — 중 (기본 빼기)

- **덜어 주는 불편**: 새 학기에 학생 얼굴과 이름을 익히기 어렵다.
- **기본은 빼 둔다.** 학생 사진은 가장 민감한 자료다. 쓰려면 **교육청·학교 지침**(이용 목적·보는 사람·보관 기간)을 먼저 확인하고 `progress.md`에 적는다.
- **흐름(원본 학교)**: 관리자가 정한 명단의 선생님만 반별 사진 카드와 이름 찾기를 본다. 학교가 받은 사진 명렬표 파일은 운영자가 가져오기 스크립트로만 넣는다.
- **지킬 것**: 관리자도 명단에 있어야 본다(시험용 관리자 계정이 못 보게 — 함정 111). 표와 버킷을 DB 함수 하나로 막는다. 열람 기록·내려받기·AI 도구는 두지 않는다. 사진 서명 주소는 보는 분의 세션으로 만든다. 가져오기는 허용한 글만 남기고(전화번호 버림), 출력에 학생 이름을 찍지 않고, 원본 파일을 서버에 두지 않는다. 학년도가 바뀌면 지운다. → `05-보안기준선.md` G
- 원본 학교 규모: 약 900줄.

### 학교 행사성 기능과 날씨 안내 — 하~중 / 중

한 번 쓰고 마는 행사나 그날 날씨에 따라 바뀌는 안내다. 학교마다 행사가 달라 그대로 옮기기보다 **예시로** 본다.

- **학교 행사 화면**(`sports`, 예: 반 대항 경기 대진표): 담당 선생님이 대진과 결과를 적고, 홈·현황판에 오늘 경기·결과 카드가 뜬다. 경기 시각을 잡으면 그 시간에 관련된 선생님(두 반 수업 교사·담임)께 알린다. 새 표 없이 설정 한 칸에 담고, 행사가 끝나면 지운다 — 메뉴에서도 저절로 빠진다. 학생 이름은 싣지 않는다(반 이름만). 원본 학교 규모: 약 1,000줄.
- **날씨 따라 바뀌는 안내**(`rainpe`, 예: 비 오는 날 체육 장소): 비 예보나 관측이 잡히면, 담당 선생님이 고른 수업 장소를 그 반 교실 칠판 쪽지와 담임 알림으로 보낸다. 보내기는 1분 틱 한 곳에서만(두 사람이 동시에 눌러도 쪽지가 두 장 뜨지 않게). 학생이 보는 칠판에 나가므로 처음엔 관리자 미리 보기로 시험한다. 공공데이터 날씨는 가끔 멈추고 늦다(함정 108). 원본 학교 규모: 약 700줄.
