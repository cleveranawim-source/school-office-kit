# 모듈 카탈로그

원본 학교의 「AI 교무실」의 모듈 23개를 정리했다. 모듈마다 **어떤 불편을 덜어 주는지**, **무엇이 먼저 있어야 하는지**, **학교마다 무엇이 다른지**를 적었다.

- 규모는 원본 학교 코드 기준 대략치(테스트 제외)다. 난이도를 가늠하는 데만 쓴다.
- 분류는 다른 학교 기준 제안이다: **핵심**(먼저, 거의 모든 학교) / **추천**(대부분 쓸모) / **선택**(학교 사정 따라).
- 인터뷰에서 선생님이 말한 「불편」을 아래 「덜어 주는 불편」 칸과 맞춰 본다.

## 핵심

### 로그인·계정 — 중

- **덜어 주는 불편**: 링크만 알면 누구나 보던 자료(패들렛 등)를 교직원만 보게.
- **흐름**: 운영자가 명단으로 계정을 한꺼번에 만든다 → 초기 비밀번호 배부 → 교사는 이름 + 비밀번호로 로그인 → 첫 로그인 때 비밀번호 변경. 명단 밖 교직원(교장·보건 등)은 따로 추가.
- **데이터**: `profiles`(이름, 부서, 역할, 활성, 비밀번호 변경 필요, 호칭).
- **학교마다 다른 것**: 로그인 방식(이름+비밀번호 / 학교 구글 계정) — `04-뼈대설계.md` 2절.
- **지킬 것**: 퇴직자는 지우지 않고 비활성화. 로그아웃은 전체 새로고침 이동(앞사람 화면이 남지 않게).
- 원본 학교 규모: 약 830줄.

### 관리 (관리자만) — 중

- **덜어 주는 불편**: 학기마다 바뀌는 값(교시 시각, 담임, 외부 링크, 안내문)을 바꿀 때마다 코드를 고쳐야 하는 일.
- **흐름**: 교사 관리(비밀번호 초기화·역할·비활성화·부서), 시간표 업로드, 설정 카드(쓰는 모듈마다 하나), AI 평가 보기.
- **데이터**: `settings`(키-값), `profiles`, `homerooms`.
- **지킬 것**: 설정 표는 교사가 읽지 못하게. 비밀 주소(캘린더 비공개 주소, 시트 토큰)는 화면 밖으로 새지 않게.
- 원본 학교 규모: 약 2,480줄(설정 카드 11개).

### 시간표 — 중

- **덜어 주는 불편**: 시간표 엑셀을 휴대폰으로 열어 확대해 보던 일. 「지금 빈 교실·빈 선생님」 찾기.
- **흐름**: 관리자가 시간표 파일을 올림 → 변환 미리보기(통계·경고·계정 없는 교사) → 적용. 교사는 교사/학급/교실/전체 탭으로 보고, 지금 교시가 강조된다.
- **데이터**: `timetable_versions`(JSON, 현재 판 하나), 설정 `period_times`(교시 시각).
- **학교마다 다른 것 — 가장 크다**: 시간표 프로그램의 내보내기 형식이 학교마다 다르다. **변환기는 새로 쓴다.** 인터뷰 때 받은 시간표 파일 하나(실명 지운 것)로 시작하고, 변환 결과를 손으로 대조하는 테스트를 둔다. 나이스 공개 API의 시간표로 대신할 수 있는지도 확인해 본다.
- **지킬 것**: 「현재 시간표」는 언제나 하나(SQL 함수로 원자적 전환). 교사는 이름으로 맞추므로 동명이인 주의.
- **중요**: 진도표, 업무 요청 배달, 보건 알림, 칠판 쉬는 시간 잠금, 홈, AI가 모두 「지금 수업 중인가」를 여기서 묻는다.
- 원본 학교 규모: 약 1,430줄.

### 일정 — 중

- **덜어 주는 불편**: 학사일정 엑셀과 캘린더를 따로 보던 일.
- **흐름**: 관리자가 구글 캘린더 주소(ICS)를 넣고 동기화. 화면을 열 때 1시간 지났으면 다시 읽는다(크론 불필요). 공휴일 캘린더도 함께. 관리자 직접 입력 가능.
- **데이터**: `events`(출처: 직접/캘린더/공휴일, 외부 id).
- **학교마다 다른 것**: 일정을 어디서 관리하는지(구글 캘린더 / 나이스 학사일정 / 엑셀). 출처별 읽기 부분만 바꾼다.
- **지킬 것**: 비공개 캘린더 주소는 비밀. 가져오기 실패 시 기존 일정을 그대로 둔다. 종일 일정은 서울 자정 기준(`06-함정노트.md` 12).
- 원본 학교 규모: 약 1,500줄.

### 공지 — 하~중

- **덜어 주는 불편**: 메신저 쪽지에 묻혀 사라지는 전체 공지.
- **흐름**: 관리자가 공지(첨부 3개, 링크 5개)를 올리면 전체 푸시. 고정하지 않은 공지는 24시간 뒤 목록에서 내려가고, 30일 뒤 첨부까지 지운다.
- **데이터**: `notices`, 비공개 버킷.
- **지킬 것**: 보존 기한 숫자가 코드·DB 정책·목록 질의 세 곳에 있으면 함께 바꾼다.
- 원본 학교 규모: 약 1,190줄.

### 급식 — 하

- **덜어 주는 불편**: 급식 메뉴 찾아보기. 아침·점심 알림에 함께 실려 체감이 크다.
- **흐름**: 이번 주 중식 메뉴(알레르기 번호 포함)를 주 단위로 넘겨 본다.
- **데이터**: 표 없음. 나이스 교육정보 개방 포털의 급식 API를 6시간 캐시.
- **학교마다 다른 것**: 교육청 코드·학교 코드 두 개뿐. **가장 옮기기 쉬운 모듈**이라 첫 성공 경험으로 좋다.
- 원본 학교 규모: 약 300줄.

### 자료실 — 중 (AI 색인까지 하면 상)

- **덜어 주는 불편**: 패들렛·밴드·공유 폴더에 흩어진 양식, 권한·검색이 약한 자료 게시판.
- **흐름**: 교사 누구나 링크·파일(20MB 이하)·글을 올린다. 부서 섹션과 검색으로 찾는다. 링크는 앱 안 보기 화면으로 연다. 관리자는 고정·공개 범위(관리자만)·「AI가 읽지 않음」을 정한다.
- **데이터**: `library_sections`, `library_posts`, `library_texts`(AI 색인), 비공개 버킷.
- **학교마다 다른 것**: 부서 섹션 목록, 기존 자료가 있는 곳(→ 이관 스크립트를 그에 맞게 새로).
- **지킬 것**: 파일은 서명 주소로 직접 업로드. 고정·공개 범위는 트리거로 관리자만. 민감 자료(계정 정보, 학생 명렬표)는 관리자만 + AI 제외. 옮겨 오는 기존 도구와 **한 학기 병행**.
- 원본 학교 규모: 약 3,480줄(색인 포함).

### 홈 — 중

- **덜어 주는 불편**: 아침마다 여러 곳을 열어 보던 일 — 「오늘 무엇이 있나」를 한 화면에.
- **흐름**: 날짜·날씨·한 문장 요약(수업 N시간, 공강, 첫 일정), 오늘 일정, 처리할 요청 N건, 오늘 시간표(누르면 진도표), 공지, 급식, 주간소식. 퇴근 뒤·주말은 다음 수업일 문장으로.
- **학교마다 다른 것**: 학교 관행에 맞는 줄(원본 학교는 아침 모임 인도자·등교 지도 교사).
- **지킬 것**: 날씨 같은 부가 정보를 기다리지 않는다(따로 떼어 늦게 그리기).
- 원본 학교 규모: 약 660줄. 다른 모듈이 생길 때마다 카드가 늘어나므로, 처음엔 껍데기로 시작해 키운다.

### 알림(웹푸시) — 중

- **덜어 주는 불편**: 아침마다 화면을 열어 확인하던 일. 이후 모든 즉시 알림(업무 요청·결석·보건·서명)의 통로가 된다.
- **흐름**: 교사가 기기마다 「알림 켜기」(아이폰은 홈 화면 추가가 먼저). 평일 아침(07:50)·점심(11:30) 요약 푸시. 누르면 그 화면으로.
- **데이터**: `push_subscriptions`, 설정(마지막 실행·결과·시험 잠금).
- **학교마다 다른 것**: 요약에 넣을 내용(지도 교사 순번 등이 학교 시트에 있으면 그 파서).
- **지킬 것**: 하루 한 번 보장(보내기 전 선점), 죽은 구독 정리, 활성 계정만, 주말·공휴일 쉼, 시험 잠금. → `06-함정노트.md` 5절
- 원본 학교 규모: 약 1,880줄.

### 담임 배정 — 하

- 관리 > 설정에 「2-3 홍길동」처럼 한 줄씩. 결석 접수·보건 알림·칠판 학급 목록·AI 도구가 쓴다. 독립 화면 없이 관리 카드 하나로 시작한다.

## 추천

### 진도표 — 하~중

- **덜어 주는 불편**: 반마다 어디까지 나갔는지 기억에 의존. 대신 들어간 수업에서 그 반 진도를 모름.
- **흐름**: 「오늘 적기」에 그날 내 수업마다 한 줄. 「이 반 진도」는 그 반을 가르치는 교사 모두의 기록. 「진도 지도」(반×주 격자)는 넓은 화면에서만, 휴대폰은 한 주씩 넘기기.
- **데이터**: `lesson_logs`(교사·날짜·교시 유일).
- **학교마다 다른 것**: 거의 없다.
- **지킬 것**: 진도 지도는 **본인 것만**, 관리자도 남의 지도를 못 연다.
- 원본 학교 규모: 약 1,290줄.

### 업무 요청 「넵」 — 상

- **덜어 주는 불편**: 메신저는 보내기까지만 해서 누가 읽었는지·끝냈는지 모른다. 지시가 쪽지 아래로 묻힌다. 첨부를 다시 요청하는 일이 반복된다.
- **흐름**: 누구나 알림·확인요청·업무요청·제출요청을 보낸다(받는 사람: 전체·부서·학년·개인, 마감·예약·긴급). 받는 사람은 [넵]·[완료]·[제출] **하나만** 누른다. 보낸 사람은 현황판(N/전체)과 [다시 알림](하루 1회). 「나에게」 보내면 다음 근무일 아침에 오는 개인 할 일.
- **배달 규칙**: 받는 사람 기준 — 수업 중이면 교시 끝에, 근무 시간 밖이면 다음 근무일 아침에, 긴급만 즉시(월 한도).
- **데이터**: `neps`, `nep_receipts`(배달 시각·읽음·완료·제출물·다음 리마인드), 1분 크론.
- **학교마다 다른 것**: 근무 시간. 부서·학년 대상 발송은 **부서 값이 채워져 있어야** 한다(원본 학교는 71명 중 10명만 있었다 → 조직표 모듈).
- **지킬 것**: 배달·리마인드 규칙은 순수 함수 하나가 정본이고 테스트로 지킨다. 판정 기준 「근무 시간 밖에 도착한 알림(긴급 제외) 0건」. 받는 사람은 남의 처리 기록을 못 본다. 닫힌 지 30일 뒤 목록에서, 90일 뒤 삭제.
- 원본 학교 규모: 약 1,410줄. 배달 엔진을 먼저 순수 함수 + 테스트로 만든다.

### 조직표 — 중

- **덜어 주는 불편**: 「교무부에게」, 「부장단에게」 보내기가 안 됨.
- **흐름**: 학기마다 업무분장·명렬표 파일을 넣어 부서·학년부·교과·직책을 채운다. 보여 주는 화면 없이 **받는 사람 고르기에만** 쓴다.
- **학교마다 다른 것**: 업무분장 파일 형식(→ 파서를 새로 쓰거나 관리 화면에서 직접 입력).
- **지킬 것**: 명렬표의 연락처·내선은 읽지도 저장하지도 않는다. 원본 파일은 저장소에 넣지 않는다.

### 주간소식 — 중

- **덜어 주는 불편**: 교무부 주간 일정 PDF를 각자 열어 보던 일.
- **흐름**: 주간 일정표·월 주요일정은 일정 모듈에서 자동, 부서 알림·안내문만 관리자가 적는다. 매주 같은 안내는 「상시 안내」에 한 번. 「발행」을 눌러야 보이고 푸시가 나간다.
- **학교마다 다른 것**: 원본 학교는 공개 드라이브의 PDF를 AI가 읽어 초안을 만든다. 다른 학교는 **수동 입력판부터** 시작하고, 자동 초안은 나중에.
- **지킬 것**: 발행한 호는 자동 초안이 덮어쓰지 않는다. 발행은 사람이 눈으로 보고.

### 내 서명 — 중

- 손 서명(그리기)과 도장(사진에서 바탕 지우기)을 등록해 기본 하나를 정한다. 서명 모듈·수업교체의 기반.
- **지킬 것**: 본인 서명만 읽는다(관리자도 못 봄). 파일은 서버만 올리고, PNG 형식·크기 검사. 바꿀 때마다 새 경로에.

### 서명 (회의 서명부·파일 서명) — 상

- **덜어 주는 불편**: 종이 서명부 돌리기. 서명 받을 일이 생길 때마다 새 기능을 만드는 일.
- **흐름**: 회의 서명부 — 회의명·일시·참석자 → 알림 → 참석자가 [내 서명으로 서명] 한 번 → A4 PDF. 파일 서명 — 서식 파일(PDF·hwpx)을 올리면 `(서명)`·`(인)` 자리를 찾아 주인을 정하고, 각자 서명하면 원래 형식 그대로 서명된 파일.
- **지킬 것**: 본인이 누를 때만 서명이 들어간다. 서명 순간의 사본을 문서 쪽에 남긴다. 완성 파일은 요청자·관리자만. 전자결재를 대신하지 않는다.
- 회의 서명부부터, 파일 서명은 나중에.

### AI 도우미 — 상

→ `07-AI도우미.md`. 읽을 모듈이 몇 개 생긴 뒤에 붙인다. **읽기 도구부터**, 확인 카드는 나중에.

### 신청 — 하~중

- **덜어 주는 불편**: 구글 시트 십여 개에 흩어진 신청(가정통신문 번호, 기기 수리, 특별실 예약, 희망도서) — 매번 시트를 찾아 칸에 적기.
- **흐름**: 1차는 자료실의 시트 링크 모음 + 학교 서식(hwpx) 채우기. 2차는 AI에게 말하면 확인 카드 → [등록] → 시트마다 붙인 Apps Script 창구가 빈 행에 기록.
- **지킬 것**: 시트 쓰기는 사람이 [등록]을 눌러야만. 신청자 이름은 로그인 프로필에서만. 창구는 토큰 없이 응답하지 않는다. 시험은 시트 사본으로.

## 선택

### 결석 접수 — 중

- **덜어 주는 불편**: 전화·문자로 흩어진 결석 연락, 손으로 쓰는 출결 신고서.
- **흐름**: 보호자가 카카오톡 채널에 「결석」 → 학반·이름·종류·날짜·사유를 대화로 → 담임 이름으로 답장, 담임·관리자에게 푸시 → 담임이 처리 상태를 바꾸고 출결 신고서(hwpx)를 받는다.
- **학교마다 다른 것**: 학부모 창구(카카오 채널 운영 여부, 다른 앱), 출결 서식. 봇의 두뇌(대화 흐름)를 메신저와 분리해 두면 창구를 바꾸기 쉽다.
- **지킬 것**: 담임과 관리자만 본다. 카카오 5초 제한(`06-함정노트.md` 62). **건강 정보가 담기므로 지난 학년도 접수는 4월에 자동 삭제.**

### 체험학습 신청 — 하~중

- 결석 접수와 같은 봇에 얹는다. 기간·장소·목적·계획·보호자·인솔자를 받아 학교 신청서 서식을 채운다.

### 보건실 — 하~중

- **덜어 주는 불편**: 학생이 보건실에 간 줄 몰라 결석으로 오해하거나 찾아다니는 일.
- **흐름(원본 학교)**: 학교가 쓰는 보건실 프로그램의 「담임 공유」 화면을 새 창으로 열고, 1분마다 공유 자료를 읽어 새 입실을 담임과 그 교시 교과 교사에게 푸시.
- **학교마다 다른 것**: 보건실 프로그램. 공유 기능이 없으면 이 모듈은 빼는 것이 낫다.
- **지킬 것**: 학교 관행(반·성별만)보다 더 기록하지 않는다. 교과 교사에게는 수업 중·시작 5분 안 입실만.

### 교실 칠판 알림 — 상

- **덜어 주는 불편**: 반에 전할 말이 있으면 전화하거나 사람을 보내던 일. 재난 때 방송이 닿지 않을 경우의 두 번째 통로.
- **흐름**: 교사가 대상 교실에 안내(링크를 붙이면 큰 QR)나 긴급(경보음)을 보낸다. 교실 칠판은 로그인 없이 교실별 토큰 주소를 전체화면으로 열어 둔다. 안내는 칠판 터치로 확인, 긴급은 보낸 사람이 종료.
- **학교마다 다른 것**: 칠판 기종·운영체제, **학교 보안점검 기준**(화면보호기·잠금). 원본 학교는 윈도우용 작은 프로그램까지 만들었다. 다른 학교는 **크롬 키오스크 + 웹 화면만으로** 시작한다.
- **지킬 것**: 토큰이 곧 열쇠(`05-보안기준선.md` E). 폴링 간격 정책(무료 한도 초과 사례). 쉬는 시간 잠금. 학생 이름이 남을 수 있어 7일 뒤 삭제.
- 시작 전에 학교 정보 담당과 교실 PC 설정을 상의한다.

### 세특 도우미 — 상

- **덜어 주는 불편**: 과세특·동아리·행발 초안 작성, 나이스 엑셀 왕복.
- **흐름**: 나이스 내보내기 엑셀을 올리고 활동 기록으로 학생마다 초안을 만들고, 검증(분량·금지어)을 거쳐 지정한 열만 채운 엑셀로 내려받는다.
- **지킬 것**: **학생 이름을 프롬프트에 넣지 않는다.** 학생 기록을 서버에 남기지 않는다(브라우저에만). 교사 개인 API 키를 받는다면 `05-보안기준선.md` H.
- **학교마다 다른 것**: AI 비용 주체(학교 키 / 교사 개인 키), 그 해 기재요령.

### 수업교체 — 하~상

- **덜어 주는 불편**: 결강 교체를 사람이 맞춰 보고 신고서를 손으로 쓰던 일.
- **원본 학교**: 교체 계산은 다른 교사가 만든 별도 앱을 쓰고, 사이트는 요청·상대 수락(=서명)·교무부 제출함·신고서(hwpx)를 맡는다.
- **다른 학교에서는**: 교체 규칙이 학교마다 달라 가장 학교 특수다. **처음엔 신고서 채우기 + 상대 수락만** 두고, 계산 엔진은 나중에 이 학교 규칙으로 새로 쓴다. 시간표는 사이트 것 하나만 쓴다(두 벌이 되지 않게).

### 교과협의록 — 하~중

- 이미 쓰는 협의록 앱이 있으면 화면 안에 띄운다(iframe). 없으면 자체 표나 문서 링크로 시작한다. 회의 서명부와 이어 붙일 수 있다.
