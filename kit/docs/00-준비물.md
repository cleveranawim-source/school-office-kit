# 준비물 — 0단계

1단계(뼈대)를 시작하기 전에 갖출 것들이다. 에이전트는 이 목록을 선생님과 하나씩 확인하고 `progress.md`에 적는다.

## 1. 계정

| 서비스 | 하는 일 | 비고 |
|---|---|---|
| GitHub | 코드 보관, 배포 연결 | 저장소는 **비공개**로 |
| Supabase | 데이터베이스, 로그인, 파일 저장 | 서울(ap-northeast-2) 지역 선택 권장 |
| Vercel | 사이트 배포(주소 생성) | GitHub 저장소와 연결하면 푸시할 때 자동 배포 |
| AI 회사(선택) | AI 도우미 | Anthropic 또는 OpenAI. 학교 예산 결제 여부 먼저 정하기 |

**계정 명의는 학교 공용 메일을 권한다.** 이유와 방법은 `08-인수인계.md`.

## 2. 무료 요금제로 시작할 때 알아 둘 것

2026년 10월에 확인한 내용이다. 요금제는 바뀌므로 가입할 때 다시 확인한다.

**Supabase 무료**
- 7일 동안 아무 요청이 없으면 프로젝트가 **일시 정지**된다(자료는 남지만 사이트가 멈춘다). 학기 중에는 매일 쓰므로 괜찮지만, **방학**이 걱정이면 매일 도는 크론 하나가 있으면 막힌다. 또는 유료(Pro)로 옮긴다.
- **자동 백업이 없다.** 학기 중 중요한 자료가 쌓이기 시작하면 유료로 옮기거나, 정기적으로 직접 내보내기를 한다.
- 데이터베이스 500MB, 파일 1GB. 교직원 100명 규모의 글·일정에는 넉넉하지만, 자료실에 파일을 많이 올리면 금방 찬다 → 큰 파일은 드라이브 링크로.

**Vercel 무료(Hobby)**
- 개인·비상업 용도 요금제다. 학교 업무용으로 써도 되는지 애매하면, 학교 명의 유료(Pro)로 가거나 관리자와 상의한다.
- 크론(정해진 시각에 자동 실행)이 **하루 한 번까지**이고 시각도 그 시간대 안에서 들쭉날쭉하다. 아침 7시 50분 알림처럼 정확한 시각이나 1분마다 도는 일은 Supabase의 `pg_cron`으로 돌린다(`04-뼈대설계.md`).

**AI 비용 참고 (원본 학교 실제)**
- 교직원 약 70명, AI 도우미 사용 초기 한 달 약 $16(가장 비싼 모델을 쓸 때).
- 모델을 중간급으로 바꾸고 프롬프트 캐시를 켠 뒤 질문 하나에 약 1~3센트.
- 쓰는 양은 학교마다 크게 다르므로, **회사 콘솔에서 월 지출 한도**를 먼저 걸어 둔다.

## 3. 컴퓨터

- Node.js(LTS 버전)와 git
- Claude Code 또는 Codex
- 휴대폰 실제 확인용으로 아이폰과 안드로이드를 각각 하나씩 빌릴 수 있으면 좋다(교직원 휴대폰 확인은 1단계 관문에 들어 있다)

## 4. 사람

- 학교 관리자와의 합의(무엇을, 누가 운영, 비용은 어디서)
- 시범 사용자 3~5명(첫 공개 전에 써 볼 선생님)
- 학교 정보보안 담당께 확인할 것: 교직원·학생 정보를 해외 클라우드에 두는 것, 개인정보 처리 범위. 학교·교육청마다 지침이 다를 수 있다.
