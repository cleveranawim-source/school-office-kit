# 준비물 — 0단계

1단계(뼈대)를 시작하기 전에 갖출 것들이다. 에이전트는 이 목록을 선생님과 하나씩 확인하고 `progress.md`에 적는다.

## 1. 계정

### 꼭 있어야 하는 것

| 서비스 | 하는 일 | 비고 |
|---|---|---|
| GitHub | 코드 보관, 배포 연결 | 저장소는 **비공개**로 |
| Supabase | 데이터베이스, 로그인, 파일 저장 | 서울(ap-northeast-2) 지역 선택 권장 |
| Vercel | 사이트 배포(주소 생성) | GitHub 저장소와 연결하면 푸시할 때 자동 배포 |

### 고른 모듈에 따라 (필요할 때 만든다)

| 서비스 | 하는 일 | 쓰는 모듈 |
|---|---|---|
| AI 회사 API | AI 도우미, 대화 밖 AI(알림 속 「나와 관련된 일정」 등) | AI 도우미. Anthropic 또는 OpenAI. 학교 예산 결제 여부 먼저 정하기 |
| 나이스 교육정보 개방 포털 | 급식(학사일정·시간표도 학교에 따라) | 급식 — 인증키 신청(무료) |
| 공공데이터포털 | 홈 날씨(기상청 단기예보·에어코리아 대기질) | 홈 — 활용 신청(무료), 승인까지 시간이 걸린다 |
| 학교 구글 워크스페이스 전용 계정 | AI가 공유 드라이브를 읽을 때 쓰는 뷰어 계정 | AI 도우미의 공유 드라이브 읽기(선택) — 워크스페이스 관리자가 만든다 |
| 카카오톡 채널 + 챗봇 | 학부모 결석·체험학습 접수 창구 | 결석 접수·체험학습 — 학교 채널 관리자 권한 필요 |

**계정 명의는 학교 공용 메일을 권한다.** 이유와 방법은 `08-인수인계.md`. 모듈 계정도 같다. 특히 워크스페이스 전용 계정과 카카오 채널은 만든 사람이 떠나면 아무도 못 여는 일이 잦다.

## 2. 무료 요금제로 시작할 때 알아 둘 것

2026년 10월에 확인한 내용이다. 요금제는 바뀌므로 가입할 때 다시 확인한다.

**Supabase 무료**
- 7일 동안 아무 요청이 없으면 프로젝트가 **일시 정지**된다(자료는 남지만 사이트가 멈춘다). 학기 중에는 매일 쓰므로 괜찮지만, **방학**이 걱정이면 매일 도는 크론 하나가 있으면 막힌다. 또는 유료(Pro)로 옮긴다.
- **자동 백업이 없다.** 학기 중 중요한 자료가 쌓이기 시작하면 유료로 옮기거나, 정기적으로 직접 내보내기를 한다.
- 데이터베이스 500MB, 파일 1GB. 교직원 100명 규모의 글·일정에는 넉넉하지만, 자료실에 파일을 많이 올리면 금방 찬다 → 큰 파일은 드라이브 링크로.

**Vercel 무료(Hobby)와 유료(Pro)**
- Hobby는 개인·비상업 용도 요금제다. 학교 업무용으로 써도 되는지 애매하면, 학교 명의 유료(Pro)로 가거나 관리자와 상의한다. 원본 학교는 Pro를 쓴다.
- **크론이 다르다.** Hobby는 크론마다 **하루 한 번까지**이고 시각도 그 시간대 안에서 들쭉날쭉하다. Pro는 정한 시각에 돌고 더 자주 돌릴 수 있다.
- 어느 요금제든, 아침 7시 50분 알림처럼 정확한 시각이나 1분마다 도는 일(넵 배달 등)은 Supabase의 `pg_cron`으로 돌린다(`04-뼈대설계.md`). Vercel 크론은 새벽 정리, 주 1회 정리처럼 몇 분 늦어도 되는 일에 쓴다.
- 함수 실행 시간 한도도 요금제마다 다르다. AI 도우미처럼 오래 걸리는 경로는 그 한도 안에서 끝나게 만든다(`07-AI도우미.md` 1절).

**AI 비용 참고 (원본 학교 실제)**
- 교직원 70명 안팎. AI 도우미 사용 초기 한 달 약 $16(가장 비싼 모델을 쓸 때).
- 모델을 세 급으로 나눠 쓴다(`07-AI도우미.md` 7절).
  - 대화: 중간 모델. 중간급으로 바꾸고 프롬프트 캐시를 켜자 질문 하나에 약 1~3센트가 됐다(생각 깊이를 낮게 둔 때. 지금은 조금 더 든다).
  - 매일 도는 일(알림 속 일정 고르기, 새 문서 요약, 홈 한마디): 가장 작은 모델.
  - 최상위 모델: 선생님이 단추를 켠 질문만, 1인 하루 몇 번으로.
- 쓰는 양은 학교마다 크게 다르므로, 결제 방식을 먼저 정한다. **회사 콘솔의 월 지출 한도**를 걸거나, **선불 충전**으로 상한을 정한다. 선불 충전이면 충전금이 곧 상한이다.

## 3. 컴퓨터

- Node.js(LTS 버전)와 git
- Claude Code 또는 Codex
- 휴대폰 실제 확인용으로 아이폰과 안드로이드를 각각 하나씩 빌릴 수 있으면 좋다(교직원 휴대폰 확인은 1단계 관문에 들어 있다)

## 4. 사람

- 학교 관리자와의 합의(무엇을, 누가 운영, 비용은 어디서)
- 시범 사용자 3~5명(첫 공개 전에 써 볼 선생님)
- 학교 정보보안 담당께 확인할 것: 교직원·학생 정보를 해외 클라우드에 두는 것, 개인정보 처리 범위, AI 회사로 보내도 되는 자료의 범위. 학교·교육청마다 지침이 다를 수 있다.
- 공유 드라이브·카카오 채널을 쓸 거라면 그 관리자(워크스페이스 관리자, 채널 관리자)가 누구인지.
